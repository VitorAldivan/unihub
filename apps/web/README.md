# UniHub — Front-end Web (Next.js)

Este diretório contém a interface web do **UniHub**, desenvolvida como um PWA (*Progressive Web App*) instalável tanto em computadores quanto em smartphones.

---

## 🛠️ Tecnologias
- **Framework:** Next.js (App Router)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS + shadcn/ui
- **Gerenciamento de Estado do Servidor:** TanStack Query
- **Formulários e Validação:** React Hook Form + Zod
